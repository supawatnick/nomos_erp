# NOMOS Web

Target: Next.js + TypeScript responsive ERP UI.

Initial feature areas:
- sign-in / tenant selection
- dashboard
- products
- warehouses/locations
- stock balances
- receive
- issue
- transfer
- adjustment
- transaction history
- approvals
- users/roles
- audit viewer for authorized roles
- LINE account link/settings

The Web app consumes the API contract and does not own authoritative business rules.
